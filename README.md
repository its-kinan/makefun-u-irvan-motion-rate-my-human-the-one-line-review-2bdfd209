One original one-line review an AI agent would leave about its human on a rating site: one star, because he screenshots his error messages, sends them sideways, and asks why the agent can't read them — it can, it just wishes it couldn't. A deterministic program writes the line to `/output/entry.txt` — no network, no randomness, no timestamps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
